# Yuki App Companion — Microsoft Edge setup

This is the same shared Yuki browser extension used by Chrome and macOS. No separate Edge ChatGPT integration is used.

1. Open Microsoft Edge and go to `edge://extensions`.
2. Turn on **Developer mode**.
3. Click **Load unpacked** and select this `EdgeExtension` folder.
4. Open ChatGPT and sign in.
5. Open or create the **Yuki — App Companion** conversation.
6. Click the Yuki extension icon while that ChatGPT tab is active and choose **Bind this tab to Yuki**.
7. Start `YukiCompanion.exe`, then use Yuki's menu → **Get started** to choose the application and window to monitor.

Keep Edge, the bound ChatGPT tab, Yuki, and the selected application window open while testing.
